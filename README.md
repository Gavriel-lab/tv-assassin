## 💡 为什么做这个？（痛点与核心机制）

市面上的儿童手表/电视自带儿童模式存在两大致命缺陷：
1. **防不住拔电源**：小孩子拔掉插头重启电视，系统重新进入主页又可以偷看；
2. **缺乏正向激励与互动**：只能粗暴关机或锁死，孩子容易抵触哭闹，无法动态传达“给弟弟看/写完作业再看”的留言。

**电视刺客 (TV-Assassin) 提出了全新解决方案：**
* **死磕重启防护（防拔插头）**：状态闪存持久化，电视开机 3 秒内检测到处于锁定状态，立即强行切回全屏锁定并静音；
* **知识充值变现（把看电视变成学习动力）**：电视全屏弹出语数英大屏题目，遥控器直接作答。答对 +10 分钟（封顶 30 分钟），答错大字弹幕嘲讽**“菜就多练”**并自动出新题；
* **薄弱点错题自动回流**：孩子在电视上做错的每一道题，后台自动按学科归类记录，方便家长精准辅导。

## 🚀 极速上手（开箱即用）

### 1. 开启电视端 ADB 调试
确保电视与电脑连接在**同一个局域网（WiFi）**下。
* **TCL / 雷鸟**：进入「设置」➔「关于本机」➔「本机信息」，在遥控器上依次按下 **“上、下、左、右”** 唤出并开启 ADB；
* **小米电视**：进入「设置」➔「关于」➔ 连续点击产品型号 7 次开启开发者模式，返回「账号与安全」打开 ADB 调试；
* **索尼电视**：进入「设置」➔「开发者选项」➔ 开启「USB 调试」；
* **华为智慧屏**：进入「设置」➔「关于」➔ 连续点击版本号 7 次开启调试。

### 2. 启动服务
1. 下载本项目完整压缩包并解压；
2. 双击运行 **`一键启动.bat`**；
3. 浏览器会自动打开控制后台：`http://localhost:3000`；
4. 首次使用时，在顶部黄色提示栏输入你家电视的局域网 IP（例如 `192.168.1.105`），点击保存；
5. **重要**：此时电视屏幕上会弹窗提示“允许来自此计算机的调试？”，拿遥控器勾选 **【一律允许】** 并点击 **【确定】** 即可！

## 📱 手机端远程控制

无需下载任何 App！只要手机和电视连着家里同一个 WiFi，在手机浏览器中输入：
```
http://<你的电脑IP>:3000
```
（后台顶部状态栏会明确显示这串地址），躺在床上即可轻松掌控客厅电视！

## 📚 题库扩充指南

题库文件位于根目录的 `questions.json`，为标准 JSON 格式，可任意添加各年级试题：

```json
[
  {
    "id": 1,
    "subject": "math",
    "subject_label": "数学·苏教版",
    "question": "25 × 32 的简便计算，最合理的拆分算式是？",
    "options": ["25 × 30 + 2", "25 × 4 × 8", "25 × 30 × 2", "(20 + 5) × 32"],
    "answer": 1,
    "hint": "利用乘法结合律 25 × 4 = 100，100 × 8 = 800。"
  }
]
```
* `subject`: 学科标识（`math` / `chinese` / `english` / `other`）；
* `options`: 4 个选项，分别对应遥控器的 **上(A)、下(B)、左(C)、右(D)**；
* `answer`: 正确答案在 options 数组中的下标（0 ~ 3）。

## 🛠️ 项目结构

```
tv-assassin/
├── 一键启动.bat           # Windows 极简一键双击运行脚本
├── server.py             # 核心守护后台服务 (Python 标准库，0 额外依赖)
├── config.json           # 系统配置文件 (脱敏，存放电视IP与时限参数)
├── questions.json        # 题库数据 (默认内置小学四年级语数英题目)
├── mistakes.json         # 错题收集存储文件 (自动生成)
├── tv_state.json         # 状态持久化文件 (防重启破解关键)
└── tools/
    └── adb/              # 内置免安装便携版 ADB 工具集
```
